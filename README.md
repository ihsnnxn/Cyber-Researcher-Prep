# Cyber-Researcher-Prep
A public learning journal documenting my journey toward becoming a  cybersecurity researcher, with a focus on **Windows internals, reverse  engineering, malware analysis, and vulnerability research**.

> **Note:** This is a learning portfolio. All analysis is done in isolated 
> lab environments on intentionally vulnerable or public samples. 
> No live malware is stored in this repo.

## 🎯 Objective

Preparing for entry-level cybersecurity researcher roles at agencies like 
CSIT, with a focus on:
- Reverse engineering (Ghidra, x64dbg)
- Malware analysis (FLARE VM, Procmon, PEStudio)
- Memory forensics (Volatility)
- Binary exploitation (pwntools, GDB)
- Windows internals
- Web security (PortSwigger, Burp Suite
